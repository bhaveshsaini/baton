The problem

You did everything right.
The API door is still locked.

You built the strategy. You passed the evaluation. You got funded. And then you found out the account you worked for is the one account you can't automate.

What Tradovate requires

for direct API access

  • A live, funded Tradovate brokerage account
  • A minimum balance of $1,000
  • An active API Access add-on at $25/month
  • Your own code to handle auth, sockets and retries
VS

What you actually have

a prop firm account

  • An evaluation or funded account — not eligible for API access
  • Personal API keys disabled by the firm
  • A working bot with nowhere to send its orders
  • Alerts on your phone you're filling by hand

Baton sits in the middle

Your bot doesn't need an API key, because it never talks to Tradovate. It talks to us — over a plain webhook — and we handle the execution on your account. That's the entire product.

How it works

Four steps, no code

If you can create a TradingView alert, you can automate your prop account.

01

Connect your account

Link the Tradovate account your prop firm gave you — evaluation or funded. No API key, no add-on subscription, no $1,000 balance.

02

Copy your webhook

We generate a private URL and the exact alert payload for your setup. Nothing to install and nothing to configure on Tradovate's side.

03

Paste it into your bot

Drop it in a TradingView alert, a Pine Script alert_message, or a POST request from your own code.

04

Your bot trades for you

Every signal becomes a real order with your stop and target attached — running whether your machine is on or not.

Works with your bot

Wherever your strategy lives,
it can reach your account.

TradingView is the common path, but Baton is just an HTTP endpoint. Pine Script, Python, Node, C#, a Discord bot, a model on your own machine — same webhook, same result.

  • Stops and targets attached at entry — in ticks, points, dollars, percent, or absolute price.
  • Market, limit, stop and bracket orders, plus flatten, reverse, and scale-in.
  • Duplicate protection — a repeated alert results in one position, not two.
  • Private, signed endpoints — your webhook URL is yours alone.

// Paste into the TradingView alert message box

  "token": "bt_9f3a…c21",
  "account": "apex-eval-1",
  "symbol": "MNQ1!",
  "action": "buy",
  "quantity": 2,
  "order_type": "market",
  "stop_loss":   { "type": "ticks", "value": 80 },
  "take_profit": { "type": "ticks", "value": 160 }
}
//@version=6
strategy("ORB Breakout", overlay=true)

longCond = ta.crossover(close, orHigh)

// Baton reads the alert_message on each order
if longCond
    strategy.entry("L", strategy.long,
      alert_message = '{"token":"bt_9f3a…c21",' +
        '"account":"apex-eval-1","symbol":"MNQ1!",' +
        '"action":"buy","quantity":2,' +
        '"stop_loss":{"type":"ticks","value":80}}')

if ta.crossunder(close, orLow)
    strategy.close_all(alert_message = '{"action":"flatten"}')
# Any language, any host — one endpoint.

The roadmap

What we're building

Execution is the core. Everything else exists to keep a funded account alive once a bot is driving it.

Webhook execution

The core bridge. Your bot posts a signal, we place the order on your Tradovate prop account — no API key on your side.

Server-side risk limits

Daily loss cap, max contracts, max open positions, trading-hours window. Breach one and the engine flattens and locks — regardless of what your bot sends next.

Multi-account routing

Send one signal to every account you hold, each with its own size multiplier — so an eval and a funded account can run the same strategy at different risk.

Planned

Prop firm rule presets

Trailing drawdown, consistency rules, and news lockouts modelled per firm, so the engine stops you before the firm's system does.

Planned

Journal & analytics

Every order stamped with its source signal, latency, and fill price — so you can see which bot actually earns its keep.

Planned

Mobile kill switch

Positions, per-strategy toggles, and a flatten-everything button from your phone — for when the bot is doing something you don't like.
